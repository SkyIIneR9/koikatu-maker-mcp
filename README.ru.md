# Koikatu Character Maker MCP — 0.2.0

[English documentation](README.md)

Локальный MCP-мост для **редактора персонажей Koikatu**: ассистент читает параметры, меняет внешность, выбирает волосы и одежду, получает скриншоты и сохраняет/загружает карточки. Это экспериментальный плагин Maker, отдельный от мостов для Studio.

[План развития](ROADMAP.md) · [Что проверено](TESTING.md)

## Возможности

- Чтение и пакетное изменение ползунков лица/тела по игровым именам, отмена изменений.
- Выбор четырёх частей причёски, изменение цветов, контура и длины.
- Выбор одежды и цветов текущего комплекта (coordinate).
- Поиск ресурсов игры и установленных модов.
- Камера и чистые PNG как изображения в ответе MCP.
- Новые карточки без перезаписи, проверка чтением.
- Поиск карточек и загрузка персонажа того же пола в открытый редактор.
- Резервная карточка перед изменением волос/одежды и загрузкой другой карточки.

## Установка

Нужны Windows, Python 3.13, оригинальный `Koikatu.exe`, BepInEx 5, KKAPI и Screencap из BepisPlugins. Проверено на Unity 5.6.2f1, BepInEx 5.4.23.5, KKAPI 1.46.1 и Screencap 21.1.2.1 с мужским тестовым персонажем. Женские персонажи и другие сочетания модов отдельно не проверялись. Party и Sunshine не проверены; плагин привязан к `Koikatu.exe`. Studio и Unity Editor не поддерживаются.

Закрой игру, распакуй исходники и выполни в PowerShell из папки проекта:

```powershell
.\setup.ps1 -GameRoot 'D:\Games\Koikatu' -Install
```

Замени путь на свою папку игры. Скрипт создаст `.venv`, установит зафиксированные Python-зависимости, соберёт плагин и скопирует две DLL в `BepInEx/plugins/KKMakerBridge`. Без `-Install` он только подготовит окружение и сборку. Затем выведет конфигурацию MCP с нужными путями.

Используется компилятор .NET Framework из Windows; отдельный .NET SDK не нужен. Игровые DLL берутся из твоей установки. Ожидаются `BepInEx/plugins/KKAPI.dll`, `BepInEx/plugins/KK_BepisPlugins/Screencap.dll` и `BepInEx/core/Mono.Cecil.dll`; для другой структуры папок поправь ссылки в `build.ps1`.

При первой сборке скачивается Json.Net.Unity3D 9.0.1 с проверкой SHA-256. Она получает отдельное имя `KKMakerBridge.Json`, чтобы не конфликтовать с модами. Обычная Newtonsoft.Json net35 несовместима с урезанными библиотеками этой Unity.

Запусти игру и войди в редактор. После замены DLL игру нужно перезапустить.

## Подключение MCP

Внеси конфигурацию, которую напечатал `setup.ps1`, в свой MCP-клиент. Пример:

```json
{
  "mcpServers": {
    "koikatu_maker": {
      "command": "D:\\Tools\\MakerBridge\\.venv\\Scripts\\python.exe",
      "args": ["D:\\Tools\\MakerBridge\\server.py"],
      "env": {"KK_GAME_ROOT": "D:\\Games\\Koikatu"}
    }
  }
}
```

`KK_GAME_ROOT` указывает клиенту на `<игра>/MCP/MakerBridge/runtime/endpoint.json`. Без переменной используется `runtime` рядом с `server.py`. Если в `BepInEx/config/local.koikatu.makerbridge.cfg` задан другой RuntimeDirectory, укажи полный путь к его `endpoint.json` в `KK_MAKER_ENDPOINT`: этот параметр имеет приоритет. Переподключи MCP-клиент после изменения конфигурации.

## 15 инструментов

| Инструмент | Назначение |
|---|---|
| `maker_status` | Подключение, версия, готовность редактора |
| `maker_get_character` | Имя, пол, параметры лица и тела |
| `maker_set_shapes` | Проверяемый пакет изменений ползунков |
| `maker_undo_shapes` | Отмена изменений массивов лица/тела |
| `maker_get_appearance` | Части волос/одежды, категории, ID и цвета |
| `maker_set_hair` | Выбор и окраска волос, длина |
| `maker_set_clothes` | Выбор и окраска одежды текущего комплекта |
| `maker_list_assets` | Поиск установленных ресурсов |
| `maker_get_camera` / `maker_set_camera` | Чтение/изменение камеры |
| `maker_capture` | PNG размером 256–2048 по каждой стороне |
| `maker_save_card` | Новая карточка и проверка чтением |
| `maker_verify_card` | Сравнение карточки с текущим персонажем |
| `maker_list_cards` | Поиск карточек по именам файлов |
| `maker_load_card` | Загрузка карточки того же пола с резервной копией |

Сначала прочитай состояние, персонажа и внешность, затем сохрани исходную карточку. Используй полученные имена параметров и категории. **ID модовых ресурсов могут меняться при каждом запуске игры** — запрашивай их заново. Названия бывают японскими, а поле `sex` в каталоге имеет разные значения в разных категориях: это не универсальный флаг 0/1.

Ползунки нормализованы: `0.5` соответствует 50 в стандартном интерфейсе. Новые значения ползунков и длины волос ограничены `0..1`; существующие значения вне диапазона читаются и сохраняются в undo. Цвет — RGB или RGBA в диапазоне `0..1`. Для одежды `colors` задаётся по номеру канала: `{"0": [0.2, 0.4, 0.3, 1]}`. После правок нужен скриншот: освещение и материалы влияют на видимый цвет.

Undo восстанавливает оба массива ползунков целиком и также отменит их ручные правки после команды моста. История очищается при загрузке карточки и выходе из Maker. Камеру сохраняй отдельно через `maker_get_camera`. Во время команды не меняй персонажа вручную.

## Восстановление и ограничения

Новые карточки лежат в `UserData/chara/male/MCP` или `female/MCP`, резервные — в `_backups`. Существующие файлы не перезаписываются. Загрузка принимает абсолютный путь или путь относительно `UserData/chara`, включая резервную карточку. Переходы за пределы папки и пути через ссылки запрещены. Поиск пропускает `_backups`.

При ошибке после начала операции проверь текущий вид и путь `backup_card`/Recovery card: эту карточку можно загрузить обратно. Таймаут не означает, что изменение не выполнилось — не повторяй команду вслепую. Скриншоты и резервные/тестовые карточки накапливаются; автоматической очистки нет.

Сохранение и загрузка вызывают игровые API и хуки модов. При загрузке временно включаются базовые разделы карточки, но **пользовательские переключатели загрузки сторонних модов сохраняют силу**. Проверяются имя, пол, стандартные ползунки, доступные мосту параметры волос и одежда текущего комплекта. Все дополнительные поля модов и попиксельное совпадение рендера не проверяются.

Прямого редактирования ABMX, Material Editor, оверлеев и аксессуаров пока нет. Изменение одежды затрагивает текущий комплект; отдельного инструмента переключения комплектов пока нет.

## Разработка

```powershell
$env:KK_GAME_ROOT = 'D:\Games\Koikatu'
.\.venv\Scripts\python.exe bridge_client.py status
.\.venv\Scripts\python.exe -m unittest discover -s tests -p 'test_*.py' -v
.\build.ps1 -GameRoot $env:KK_GAME_ROOT
.\.venv\Scripts\python.exe package_source.py
```

Прямой клиент поддерживает `--params-file request.json`. Живые проверки описаны в [TESTING.md](TESTING.md): они меняют тестового персонажа и восстанавливают его. GitHub workflow проверяет Python; компиляция плагина и тесты в игре выполняются локально.

Архив исходников собирается по явному списку файлов. Игровые DLL, моды, карточки, скриншоты, токен подключения и локальные конфигурации в него не входят.

## Устройство и удаление

MCP stdio → Python → TCP на localhost → очередь главного потока Unity → MakerAPI/ChaControl. По умолчанию `127.0.0.1:8766`; порт меняется в конфигурации плагина. При запуске создаётся случайный токен в `runtime/endpoint.json`. Не публикуй этот файл: локальные процессы с доступом к нему могут управлять мостом. Плагин разрешает игре работать в фоне.

Для удаления закрой игру, убери `BepInEx/plugins/KKMakerBridge` и запись сервера в MCP-клиенте. Карточки, скриншоты, настройки и исходники останутся.
